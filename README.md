# NoX Suite

<p align="center">
  <sub>
    Independent components. Shared contracts. One larger ecosystem.
  </sub>
</p>

<br>

<table>
<tr>

<td width="50%" valign="top">

### [NoX Yard](https://github.com/mapherez/nox-yard)

**Your Docker homelab, in view.**

A browser-based control center for Docker hosts and homelabs.

Yard automatically discovers existing containers and Compose projects, exposing health, resource usage, logs and terminals while also handling deployments, configuration changes, image updates and scheduled maintenance.

<br>

`Docker` `Compose` `Homelab` `Management`

</td>

<td width="50%" valign="top">

### [NoX Backend](https://github.com/mapherez/nox-backend)

**A shared home for NoX application data.**

The shared data layer for compatible NoX applications.

Backend provides self-hosted vault storage and synchronization with conflict detection, while also managing accounts, API keys and connections between services in the Suite.

<br>

`Storage` `Sync` `Vaults` `API`

</td>

</tr>

<tr>

<td width="50%" valign="top">

### [NoX Gateway](https://github.com/mapherez/nox-gateway)

**One connection to the tools in your Suite.**

The unified access point for tools exposed across the NoX Suite.

Instead of configuring every application separately, Gateway discovers connected products and routes authenticated requests from NoX CLI or MCP-compatible AI assistants to the service responsible for each operation.

<br>

`MCP` `Discovery` `Routing` `AI`

</td>

<td width="50%" valign="top">

### [NoX Auth](https://github.com/mapherez/nox-auth)

**One login across participating NoX applications.**

A shared authentication service for applications across the Suite.

It centralizes Google-backed authentication, allowed accounts and persistent sessions so participating applications can reuse the same NoX Login instead of implementing and configuring authentication independently.

<br>

`Authentication` `OAuth` `Sessions`

</td>

</tr>

<tr>

<td width="50%" valign="top">

### [NoX CLI](https://github.com/mapherez/nox-cli)

**Your Suite, at your fingertips.**

An interactive terminal interface for accessing the capabilities of the NoX Suite.

CLI discovers the applications available through Gateway and turns their exposed operations into searchable, keyboard-driven menus, while securely storing credentials using the operating system's credential store.

<br>

`CLI` `Cross-platform` `Gateway`

</td>

<td width="50%" valign="top">

### [NoX MCP](https://github.com/mapherez/nox-mcp)

**The shared integration layer behind NoX.**

The shared integration layer behind AI and tool interoperability across NoX applications.

It provides TypeScript, Go and Rust libraries for defining discoverable tools, validation, authorization, discovery and shared Suite contracts, allowing each application to expose its own capabilities through a consistent MCP interface.

<br>

`TypeScript` `Go` `Rust` `MCP SDK`

</td>

</tr>
</table>

<br>

> **Modular by design.**  
> NoX applications and infrastructure components can evolve independently, while shared contracts allow them to work together as a larger system.
